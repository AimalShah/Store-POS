# Store POS — Cashier Quick Reference

## Sign In
- **PIN**: Tap 4+ digits → auto-submits
- **Password**: `admin` / your password

---

## Till Shortcuts
| Key | Action |
|-----|--------|
| **Enter** | Add scanned/searched item |
| **F2** | Open payment |
| **F4** | Held orders |
| **Esc** | Close payment modal |

---

## Making a Sale

### 1. Add Items
- Tap **category tab** (Pizzas, Drinks, etc.)
- Or **Search** tab → type name / scan barcode → **Enter**
- Items with **Options** badge → select Size / Toppings → **Add**

### 2. Cart (Right Side)
- `+/-` → change quantity
- Tap item → set **discount** (flat or %)
- **Customer** chip → pick saved or **One-time**
- **Fulfillment**: Dine-in / Takeaway / Delivery
  - Delivery = requires name, phone, address
- **Order discount** (bottom) → flat amount off subtotal
- **Hold** → parks order (bell icon shows count)
- **Clear** → instant reset

### 3. Payment (F2 or Pay)
| Tab | When to Use |
|-----|-------------|
| **Cash** | Enter tendered → shows change |
| **Card** | Exact amount |
| **Mobile** | Exact amount |

**Split payment**: Add multiple lines (e.g., Cash 50 + Card 30)
- **Pay Now** when paid ≥ total

### 4. Receipt
- **Print** (big button) → thermal printer
- **Close** → no print, back to empty cart

---

## Held Orders
- **Bell icon** (top bar) → count badge
- Click → **Resume** or **Discard**

---

## Common Scenarios

### Customer Wants Receipt Reprinted
1. Dashboard → **Sales** → find order
2. Click **Print** on that row

### Wrong Item Added
1. Cart → `−` to reduce qty to 0 (auto-removes)
2. Or **Trash** icon on item row

### Need to Apply Discount
- **Per item**: Tap item row → set discount
- **Whole order**: Bottom of cart → Order Discount

### Customer Pays Part Cash, Part Card
1. Payment → **Cash** tab → enter cash amount → **Add**
2. **Card** tab → enter remainder → **Add**
3. **Pay Now**

### Delivery Order
1. Fulfillment → **Delivery**
2. Customer chip → pick customer (auto-fills) OR **One-time** → enter name, phone, address
3. Proceed to payment

### Void a Sale (Manager Only)
1. Dashboard → **Sales** → find order
2. **Void** → confirms
3. Stock restored, marked voided

---

## End of Shift
1. Top bar → **Drawer Open** dropdown → **Close Drawer**
2. Count physical cash → enter total
3. **Close Drawer** → prints Z-report summary

## Troubleshooting

| Problem | Quick Fix |
|---------|-----------|
| "Server not responding" | Close app, reopen |
| Barcode won't scan | Click Search tab first |
| Receipt prints garbage | Settings→Printers→Test→check width 58/80 |
| Cash drawer won't open | Not supported in v3.0 |
| Forgot PIN | Use password login |
| Low stock alert | Tell manager to restock |
